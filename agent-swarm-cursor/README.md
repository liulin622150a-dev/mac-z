# Agent Swarm Build

复刻抖音视频"几十个鼠标同时操作，AI 智能体集群几分钟搭出网页"的效果：页面先变空，一群彩色鼠标飞来飞去，每个鼠标框选一个元素、标出尺寸、打字或铺开图像，页面被一块块"搭"出来；底部显示 `N agents · x / y layers` 进度，视口自动跟随（Touring）。

## 原理

视频里并不是真的有几十个 AI 在实时写代码，而是一个**叠加在已完成网页上的回放动画**：

1. **拆图层**：遍历 DOM，把"自带文字的元素、图片/SVG/按钮等媒体、有背景或边框的块"收集成 layer 列表（视频里的 `614 layers`）。
2. **先全部藏起来**：给每个 layer 加 `visibility:hidden`，页面变成空白，但布局不变，所以位置都还能量出来。
3. **任务队列 + 多个 agent**：layer 按文档顺序进入队列；每个 agent 是一个绝对定位的彩色鼠标 SVG，循环"取任务 → 飞过去 → 干活 → 取下一个"。agent 数量随时间增长（视频里从 20 涨到 70+）。
4. **干活的表现**：
   - 飞行：二次贝塞尔曲线 + 缓动，看起来像人手移动；
   - 选框：带角点和 `宽 × 高` 标签，颜色和鼠标一致；
   - 文字：`clip-path` 从左向右按字数分步展开 + 闪烁光标，模拟打字；
   - 图片：自上而下擦除 + 去模糊；色块：淡入；
   - 落点时溅出几个 `+` 粒子。
5. **HUD 与跟随**：底部胶囊显示 agent 数、完成层数和进度条；Touring 模式按"已完成的最下方位置"平滑滚动页面，用户手动滚动时暂停跟随。

## 使用

- **看演示**：用浏览器打开 `demo.html`。
- **用在任意网站**：打开目标网页 → F12 打开 DevTools → Console 粘贴 `swarm.js` 全部内容回车（部分网站的 CSP 会拦截，换一个站点即可）。
- **嵌进自己的页面**：

```html
<script>window.AGENT_SWARM_OPTIONS = { maxAgents: 60, speed: 1 }</script>
<script src="swarm.js"></script>
```

手动控制时加 `data-manual`，再调用 `AgentSwarm.start({...})` / `AgentSwarm.stop()`。

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `startAgents` | 6 | 初始鼠标数 |
| `maxAgents` | 80 | 最多鼠标数 |
| `spawnEveryMs` | 350 | 每隔多久新增一个鼠标 |
| `speed` | 1 | 全局速度，HUD 上可切 1x/2x/4x |
| `touring` | true | 是否自动滚动跟随 |
| `colors` / `names` | — | 鼠标颜色、日志里的 agent 名字 |

## 录成视频

视频是用相机拍屏幕的，想要同样的质感：浏览器全屏、深色网站、速度设 1x，用手机或运动相机斜着拍屏幕；想要干净的录屏就用 OBS 直接录。
